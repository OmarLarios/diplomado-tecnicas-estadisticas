# 📚 Técnicas Estadísticas — Diplomado

Repositorio que contiene apuntes, ejercicios y tareas desarrollados durante el módulo "Modelos estadísticos" del diplomado **Técnicas Estadísticas y Minería de Datos**.

## 📁 Estructura del repositorio

* **`/apuntes`**: Notas teóricas, resúmenes de fórmulas y conceptos clave organizados por clase.
* **`/ejercicios_tareas`**: Prácticas resueltas, análisis de probabilidades y entregas del diplomado.

## 🛠️ Herramientas utilizadas

* Python (Pandas, NumPy, SciPy, Statsmodels, Matplotlib/Seaborn)
* Jupyter Notebooks / Markdown
